# Support

- Bugs and wrong results: open a [problem report](.github/ISSUE_TEMPLATE/problem-report.md).
- New capabilities or interface changes: open a [change request](.github/ISSUE_TEMPLATE/change-request.md).
- Questions: open an issue, or start with the [documentation index](docs/README.md).
- Security problems: see `SECURITY.md`.

There is no paid support.
